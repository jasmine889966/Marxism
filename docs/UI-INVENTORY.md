# UI and function inventory

Baseline: `b05832246fcac69d13ff16df871a8d53fd394c10`. Generated before theme changes. This is a source inventory, not a claim of runtime acceptance.

## Architecture

- HakoClient: application composition, configuration editors, system integrations and extensions.
- HakoClientKit: profile/backup/credential/latency models. No theme changes.
- HakoClientUI: shared feature views, presentation snapshots, actions, navigation and reusable controls.
- HakoMacClient: desktop composition, window chrome, profiles and native controls.
- TV uses a separate Home / Utilities / More shell and source-includes shared types; it does not link the complete UI package.

## Functional journeys

| Area | Existing behavior to preserve |
|---|---|
| Home | Profile selection, primary action, connection issue recovery, outbound modes, traffic scopes, card customization, external/LAN IP refresh |
| Profiles | Import, preview, edit, reorder, activation, subscription refresh, credential handling, backups |
| Proxies | Groups, selection, node editing, search, sorting, latency probes, sharing |
| Rules / DNS | Active/configured rules, overrides, providers, resolvers, hosts, probes and diagnostics |
| Activity | Connections, requests, logs, detail views, filters and live statistics |
| Utilities | Network quality, STUN/NAT, LAN proxy share, core runtime, providers, diagnostics inbox |
| Settings | Geo resources, on demand, tunnel, DNS-only, tunnel/routes, core behavior, system integrations, appearance, language, developer tools |
| macOS | Menus, shortcuts, native settings, status item, resizable window, context menus, routed navigation |
| Extensions | Packet tunnel, share, controls, iOS/macOS widgets and shared containers |
